# Elevator System (Simulation Project)


## 📌 คลาสและการทำงาน

### 1. `Elevator`
* **หน้าที่:** คลาส Model แทนตัวลิฟต์ ใช้เก็บสถานะปัจจุบันของลิฟต์
* **คุณลักษณะและเมธอดสำคัญ:**
  * `currentFloor`: ชั้นปัจจุบันที่ลิฟต์อยู่
  * `direction`: ทิศทางปัจจุบันของลิฟต์ (`UP`, `DOWN`, `IDLE`)
  * `doorOpen`: สถานะประตูลิฟต์ (`true` = เปิด, `false` = ปิด)
  * `openDoor()` / `closeDoor()`: เปิด-ปิดประตูลิฟต์

### 2. `HallRequest`
* **หน้าที่:** คลาสข้อมูลแทนคำเรียกกดลิฟต์จากหน้าชั้น
* **คุณลักษณะสำคัญ:**
  * `floor`: ชั้นที่กดเรียก
  * `direction`: ทิศทางที่ต้องการไป (`UP` หรือ `DOWN`)

### 3. `HallRequestQueue`
* **หน้าที่:** บริหารจัดการคิวการกดเรียกลิฟต์จากหน้าชั้น
* **โครงสร้างข้อมูลที่ใช้:** **Queue (`LinkedList`)** แบบ FIFO (First-In-First-Out)
* **ฟีเจอร์:**
  * `addHallRequest()`: เพิ่มคำขอเรียกลิฟต์เข้าคิว (ป้องกันการกดเรียกชั้นและทิศทางซ้ำ)
  * `removeHallRequestsAtFloor()`: ลบคำขอออกจากคิวเมื่อลิฟต์มารับผู้โดยสารที่ชั้นนั้นแล้ว
  * **Linear Search (`hasSameHallRequest`, `getFirstHallDirectionAtFloor`):** ค้นหาและตรวจสอบคำขอซ้ำ หรือทิศทางของผู้โดยสารที่รออยู่ที่ชั้นนั้นๆ

### 4. `DestinationList`
* **หน้าที่:** จัดการรายการชั้นปลายทางที่ผู้โดยสารภายในลิฟต์เลือกกด
* **โครงสร้างข้อมูลที่ใช้:** **List (`ArrayList`)**
* **ฟีเจอร์:**
  * `addDestination()`: เพิ่มชั้นปลายทางใหม่โดยตรวจไม่ให้ซ้ำ
  * **Insertion Sort (`sortDestinations`):** เรียงลำดับชั้นปลายทางตามทิศทางเคลื่อนที่ของลิฟต์
    * หากขึ้น (`UP`): เรียงลำดับจากน้อยไปมาก (เช่น 2 -> 4 -> 5)
    * หากลง (`DOWN`): เรียงลำดับจากมากไปน้อย (เช่น 5 -> 3 -> 1)
  * **Linear Search (`hasDestination`):** ค้นหาว่าชั้นปลายทางมีอยู่ในรายการแล้วหรือยัง

### 5. `ElevatorController`
* **หน้าที่:** คลาสหลักในการควบคุมตรรกะและเงื่อนไขการทำงานทั้งหมดของระบบ (System Logic Controller)
* **ฟีเจอร์:**
  * `addHallRequest()`: รับและตรวจสอบความถูกต้องของการเรียกลิฟต์จากหน้าชั้น
  * `addDestination()`: รับและตรวจสอบความถูกต้องของการเลือกชั้นปลายทางเมื่อมีผู้โดยสารขึ้นลิฟต์
  * `step()`: ประมวลผลการทำงานทีละ Step (เคลื่อนที่ 1 ชั้น, เปิด/ปิดประตู, รับ/ส่งผู้โดยสาร)
  * **Linear Search (`hasWorkAhead`):** ตรวจสอบว่าในทิศทางที่ลิฟต์กำลังมุ่งไปนั้น ยังมีงาน (คำขอเรียกหรือชั้นปลายทาง) ค้างรู้อยู่หรือไม่ เพื่อตัดสินใจว่าจะเดินหน้าต่อ เปลี่ยนทิศทาง หรือหยุดพัก (`IDLE`)
  * `serveHallRequestAtCurrentFloor()`: จัดการเปิดประตูรับผู้โดยสาร ณ ชั้นปัจจุบัน

### 6. `Main`
* **หน้าที่:** คลาสสำหรับรันโปรแกรมผ่าน scanner
* **ฟีเจอร์:**
  * **Call Elevator (เมนู 1):** เมนูกดเรียกลิฟต์จากชั้นที่ต้องการพร้อมระบุทิศทาง
  * **Select Destination (เมนู 2):** เมนูเลือกชั้นปลายทางหลังจากลิฟต์เปิดรับผู้โดยสาร
  * **Elevator Movement & Status (เมนู 3):**
    * *Move One Step:* สั่งให้ลิฟต์ทำงานและเคลื่อนที่ทีละ 1 ขั้น
    * *Auto Move:* จำลองการทำงานอัตโนมัติจนกว่าจะส่งผู้โดยสารครบหมด
    * *Show Elevator Status:* แสดงผลภาพจำลองอาคารและสถานะปัจจุบันของลิฟต์ (ตำแหน่ง, ทิศทาง, สถานะประตู, คิวงาน)

## 🛠 โครงสร้างและอัลกอริทึมที่ใช้

| โครงสร้างข้อมูล / อัลกอริทึม | คลาสที่ประยุกต์ใช้ | วัตถุประสงค์การใช้งาน |
| :--- | :--- | :--- |
| **Queue (LinkedList)** | `HallRequestQueue` | จัดเก็บคิวคำขอเรียกลิฟต์จากหน้าชั้นตามลำดับก่อน-หลัง |
| **List (ArrayList)** | `DestinationList` | จัดเก็บรายการชั้นปลายทางที่ผู้โดยสารเลือกกด |
| **Insertion Sort** | `DestinationList.sortDestinations()` | จัดเรียงชั้นปลายทางให้สอดคล้องกับทิศทางเคลื่อนที่ของลิฟต์ |
| **Linear Search** | `DestinationList`, `HallRequestQueue`, `ElevatorController` | ค้นหาข้อมูลซ้ำ ตรวจสอบคำขอ และเช็กงานคงเหลือในทิศทางเคลื่อนที่ (`hasWorkAhead`) |
